# 完整已读范围检索与报告状态

2026-10-22。本轮不修改 Jev 提示词、冻结评分规则、公式或旧结果。

## 使用

选择单聊并读取日期范围，切换「聊天记录」。搜索框支持正文、已有语音转写和已识别图片文字。多个空格分隔的关键词必须同时匹配，支持全半角及大小写归一；不解释正则表达式。发送者与消息类型可以组合筛选。

每页最多渲染 50 条，最新消息在前。分页后回到搜索工具附近；⌘F（或 Ctrl+F）聚焦当前聊天搜索，Escape 清空筛选。中文输入法组词期间不提交搜索。切换会话或日期范围重置检索；搜索词只在组件内存中，不存配置、URL 或日志。

只搜索 Application Service 当前已读取的会话范围，包括最新 300 条以外的消息。不会自动读取更多历史、下载附件、转写或调用 Jev。未完整读取会显示范围提醒；缺失音频、未转写语音、没有 OCR 文字的图片不能按其未知内容匹配。

原有转写/图片文字校正入口保留，支持校正更早消息并立即刷新检索。成功缓存复用，筛选不触发识别。

## 报告状态

首屏单独显示报告范围、生成时间和需要复核的维度数。部分完成、读取范围不同、可确认的输入数量差异分开提示。无法由数量判断文字是否相同，因此即使范围和数量相同，也只称「已保存报告」，不声称最新或内容一致；后续转写/人工校正不自动改旧分数。新分析仍须主动预览确认。

## 验证

自动化覆盖 420 条范围中检索第 1 条、跨 300 条窗口的缓存转写与人工校正、Unicode/多关键词、发送者/类型组合、元数据不被搜入、50 条分页/越界归位/坏输入、报告状态与 SSR 控件。真实窗口验证筛选、零结果、清空及翻至第二页。测试不调用外部模型，不保存真实聊天截图或原文到仓库。
