# v9：可追溯、双向互动与本机图片观察

用户已确认落实六项提升；实施沿用本地优先和手动 Jev 确认，不增加外部模型服务。

1. 对话单元：按六小时会话、三十分钟话题间隔优先拆分，容量不足时在双方轮次结束处分段，并保留有限前后文；容量保护始终优先。消息只作为目标计数一次，前后文仅辅助理解。
2. 证据：保存本机消息 ID 映射（不上传），从报告支持/反证直接打开原会话的邻近上下文。旧结果没有映射时明确告知，不猜位置。
3. 双向：本机统计会话发起、是否得到回应和轮次；Jev 追加三个独立 Choice 问题判断情绪支持、邀请回应、亲近表达的互动方向。新判断不混入原五项指数。
4. 图表：数据覆盖、双向互动、可点击信号时间线；低信号与无法判断分开。旧分析和当前读取范围分别标识。
5. 媒体：系统 Vision OCR、粗分类、条码数量和帧覆盖；不保存条码内容、不识别人脸身份、不从表情推心理。分类只本地展示，匿名化只使用标注来源的文字。文字支持本地纠正，缓存持久化。
6. 评测：分类别/行为误判漏判、未判定率、运行覆盖及版本/数据集比较。支持外部独立标注数据集与来源元数据；人工编写测试和真正独立盲测明确区分。不会声称开发者自建样例证明客观准确。
7. 界面：固定设置入口，独立设置工作区，收拢转写/媒体任务，首屏五项及覆盖/待核对信息，详情按结论/依据/反证呈现。

验收：离线回归、隐私边界、匿名化映射不泄漏、容量边界、缓存复用、证据定位、UI 实际预览、原生图片合成样本验证。未经用户手动确认不调用 Jev。不自动重写旧结果。所有语义提升仍属未独立验证的实验规则。

能力来源：Apple Vision VNRecognizeTextRequest / VNClassifyImageRequest / VNDetectBarcodesRequest；TypeSafe 官方 https://docs.typesafe.ai/introduction 与 Choice 文档。原五项数值组合保持不变。
