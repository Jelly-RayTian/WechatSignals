# macOS 界面重构

采用本机 design-taste-frontend（taste-skill）的重构审计、字体、间距、颜色和可访问性规范。该技能明确不覆盖复杂仪表盘；营销页图片、hero、滚动劫持等要求不适用于本客户端。使用原生 CSS，不声称是 Apple 官方组件库。

## 审计与设计

旧界面四层状态提示、三栏重复评分、始终展开的读取工具及说明占据首屏，总览与证据堆在一条长页面。保留深绿色强调色、macOS 系统字体、会话搜索、四个工作区导航、隐私文案、手动预览确认、停止任务、全部结果及统计。

DESIGN_VARIANCE=4，MOTION_INTENSITY=2，VISUAL_DENSITY=5。改为双栏工作区，236px 会话侧栏及独立滚动的主区。64px 应用栏，34px 可展开系统状态；运行中的任务仍直接提供停止按钮，错误仍直接显示。读取工具、数据覆盖与分段矩阵按需展开。报告分总览图表及证据与解释，点击图表切换对应证据视图。本地对比表移入统计页。

冷灰中性色及单一深绿色强调色，6px 控件、10px 面板圆角。字体本地加载，没有新增字体或图片网络请求。支持跟随系统、浅色、深色，外观偏好仅存本机 localStorage。保留键盘焦点、减少动态效果、空状态、加载占位、错误状态。

## 验证

66 项回归测试、类型检查与构建通过。实际 Electron 验证浅色、深色及设置窗口，图表点击可切换对应指标的证据解释。主文本及辅助文本、主按钮的设计颜色对比度均大于 4.5:1；这不是全应用可访问性审计。断点定义了窄窗口布局，未声称已完成移动设备测试。
